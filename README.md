## **Project Title**

'Review' is the project title that helps to recall knowledge in Automated Testing and find the gaps.

## **Introduction**

The goal of the project is to cover by automated test three Use Cases and run tests in parallel.

## **Installation**

To install Project Title, follow these steps:

1. Clone the repository: **`https://github.com/yauhenFan/Review.git`**
2. Navigate to the project directory: **`cd project-title`**
3. Install dependencies: **`npm install`**
4. Start the project: **`npm run test`**
